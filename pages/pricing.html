Compare packages against your project

A small website with finished copy, a few service pages and one contact form can be scoped differently from a store with product data, an existing website to migrate and shipping rules to configure. Write down the number of layouts, the features each one needs and anything that depends on another tool.

When comparing a package and a custom quote, check what each includes for content, revisions, launch and upkeep. Ask how ongoing costs for hosting or paid tools are handled. A clear list also helps you decide which features are needed for launch and which can be added once customers start using the site.
